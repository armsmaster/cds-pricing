User guide

Build a smooth zero-coupon yield curve from OIS bid/ask quotes, preview par rates live, then export the curve as JSON.

Quick start

  1. Pick a trade date (defaults to today).
  2. Paste your OIS quotes as JSON (see format below) — the par-rate chart previews instantly.
  3. Set the max adjustment cap (default 15 bps).
  4. Press Calculate (or Ctrl/Cmd+Enter).

Input format

A JSON array of quotes; bid/ask are par rates in percentage points (14.35 = 14.35%).

[
  { "rate": "RUONIA", "tenor": "3m", "bid": 14.13, "ask": 14.38 },
  { "rate": "RUONIA", "tenor": "1y", "bid": 14.48, "ask": 14.68 }
]
  • rate — overnight index (aliases: rate_name, rate_index, index).
  • tenor — tenor code: 1w, 1m, 3m, 6m, 9m, 1y, 2y, 5y, 10y (aliases: tenor_code, code).

All quotes must share the same rate index (one curve per index).

Controls

  • Trade date — valuation date; spot and maturity dates follow the index conventions and holiday calendar.
  • Max adjustment (bps) — a hard cap on the average absolute adjustment applied to mids. Lower it to track mids closely; raise it to allow more smoothing.

Reading the results

  • Par rates — bid/ask markers with a shaded spread band, the mid, and (after Calculate) the adjusted mid the fitted curve reprices to.
  • Zero-coupon yield curve — fitted zero rates on a monthly grid; toggle annual / continuous / both (chart only).
  • Forward rate curve — the instantaneous forward implied by the curve; this is what the smoother keeps flat and hump-free.
  • Par rate adjustments — per quote: raw vs adjusted mid, the adjustment in bps, and whether the adjusted mid stays in spread (out-of-spread rows are highlighted).

How it works

Mids in illiquid markets are unreliable, so the bootstrap fits the curve by least squares while:

  • weighting each quote by reliability (inverse bid/ask spread), so wide-spread quotes absorb most of the adjustment;
  • penalizing the forward-rate slope to keep the forward curve smooth;
  • increasing smoothing only until genuine kinks are removed, never past the average-adjustment cap.

Export

The ZCYC JSON maps each node's future date to its yield (a decimal fraction) at the chosen compounding — Annual (DF = (1+y)^-T) or Continuous (DF = e^(-zT)). Use Copy or Download .json. The export compounding is independent of the chart toggle.

Notes

  • Shipped indices: RUONIA (RUB), SOFR (USD).
  • Holidays are seeded for 2024–2026; dates outside fall back to a weekend-only calendar.
  • Errors (unknown rate, bad tenor, empty or mixed-index quotes) appear in the status line under Calculate.
